# 🎀 Indonesian Cancer Society — Website Modern

Website resmi Indonesian Cancer Society yang dibangun ulang dengan **Next.js 15**, **Tailwind CSS**, dan **TypeScript**. Siap deploy ke Vercel.

---

## 🚀 Deploy ke Vercel

### Cara 1 — Vercel CLI (Paling Mudah)
```bash
npm install -g vercel
vercel
```
Ikuti petunjuk wizard, pilih **Next.js** sebagai framework.

### Cara 2 — GitHub + Vercel Dashboard
1. Push project ini ke GitHub
2. Buka [vercel.com](https://vercel.com) → **New Project**
3. Import repo dari GitHub
4. Vercel auto-detect Next.js — klik **Deploy**

---

## 🛠️ Development Lokal

```bash
npm install
npm run dev
# Buka http://localhost:3000
```

## 📦 Build Production

```bash
npm run build
npm start
```
