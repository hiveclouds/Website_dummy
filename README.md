# 🎀 Indonesian Cancer Society — Website Modern

Website resmi Indonesian Cancer Society yang dibangun ulang dengan **Next.js 15**, **Tailwind CSS**, dan **TypeScript**. Siap deploy ke Vercel.

----

## 📄 Halaman

| Path | Halaman |
|------|---------|
| `/` | Beranda — Hero, statistik, program, infografis |
| `/profile` | Profil organisasi & tabel faktor risiko |
| `/fundraiser` | Form donasi lengkap |
| `/newsletter` | Langganan newsletter |
| `/thankyou` | Konfirmasi donasi/newsletter |

---

## 🎨 Teknologi

- **Next.js 15** (App Router)
- **Tailwind CSS v4**
- **TypeScript**
- **Lucide React** (icons)
- **Google Fonts** — Cormorant Garamond + DM Sans
